I work at the intersection of **artificial intelligence** and **information security**: the two-way street where AI is used to defend systems, and where the systems themselves — the models — have to be defended. My portfolio is organized as a single research program on **adversarial machine learning and AI security**, where each project builds on the one before it.

```
 [0] The Range ───────────── a home security lab that also manufactures
      │                       labeled attack/benign telemetry
      ▼
 [1] Sentinel ────────────── AI-for-security: detection models trained
      │                       on The Range's telemetry
      ▼
 [2] Mirage ──────────────── security-of-AI: adversarial evasion that
      │                       defeats my own detector
      ▼
 [3] ★ Adversarial CAPTCHA ─ the arms race in one legible domain:
      │                       robust-to-bots, solvable-by-humans
      ▼
 [4] Aegis ───────────────── hardening: adversarial training + input
      │                       defense applied back up the stack
      ▼
 [5] Redcell ─────────────── an open-source red-team harness for LLMs
                             and agents (OWASP LLM Top 10 · MITRE ATLAS)
```

Everything maps to the frameworks practitioners actually use: **MITRE ATT&CK**, **MITRE ATLAS** (adversarial threats to AI), **OWASP LLM Top 10**, and the **NIST AI Risk Management Framework**.
